Propósito del repositorio

Este repositorio tiene como propósito almacenar y organizar las evidencias de clase de la materia de Programación 1. Aquí se guardarán las prácticas, tareas y proyectos realizados durante el curso.

Estructura del repositorio

El repositorio está organizado de la siguiente manera:

practicas: contiene las prácticas y ejercicios realizados durante las clases.
proyectos: contiene los proyectos desarrollados durante el curso.
README.md: contiene la información y documentación general del repositorio.
.gitignore: indica los archivos y carpetas que Git debe ignorar.

## Bitácora de instalación del IDE

**IDE utilizado:** Visual Studio Code (VS Code)

**Versión:** 1.138.0

Para trabajar durante el curso instalé Visual Studio Code como entorno de desarrollo para escribir y ejecutar código en Python. Como personalización adicional instalé la extensión Doki Theme para modificar la apariencia del editor.

**Problemas durante la instalación:**  
Después de instalar y configurar Doki Theme, Visual Studio Code mostró una advertencia indicando que la instalación parecía estar dañada o modificada.

**Solución:**  
Verifiqué que Visual Studio Code continuara funcionando correctamente después de aplicar la personalización. La advertencia apareció después de realizar las modificaciones visuales del tema.
